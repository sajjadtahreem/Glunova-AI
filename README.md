# Glunova-AI
AI based Gestational Diabetes Mellitus Prediction

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Output

- YES = GDM predicted
- NO = GDM not predicted

No probability is displayed.

## Research Use Only

This application is intended for research and educational purposes and
should not replace professional clinical diagnosis or medical decision-making.
